# BIST Dual Trading AI — Windows dağıtımı

[Kurulum dosyasını indir](https://github.com/mertozg/bist-dual-trading-ai_release/raw/refs/heads/main/setup.exe)

Yalnız sanal işlem uygulamasıdır. Kurulum paketi Python uygulama dosyalarını içerir. Hesap anahtarları ve portföy verileri pakete dahil değildir.

Saatlik güncelleme kontrolü kullanıcı oturumu açıkken çalışır. Güncelleme sırasında süreçler kontrollü durur, SQLite yedekleri alınır ve sistem tekrar başlar. Çalışan süreçler güvenli durmazsa güncelleme ertelenir.
